# 已确认的项目共识

确认日期：2026-11-02。

2026-11-09 补充确认系统架构，详见 [架构决策 0001](decisions/0001-system-architecture.md)。

## 产品方向

帮助希望重新接触民族文化和语言的东乡族年轻人，探索东乡族文化，学习日常东乡语，并接触歌曲等有声内容。长期保留文化保存与个人技术成长目标。

首版采用适配手机的网站，通过微信分享链接进入。基础浏览免登录；收藏、学习记录、个人内容创建等需要个人数据的功能后续再展开。

文化探索与语言入门都是产品方向。语言内容从称呼、问候和家庭日常短句开始。歌曲是平台的一个栏目，初期可提供介绍与经过验证的原始收听入口。

## 技术与开发方式

- React + TypeScript 前端。
- Java + Spring Boot 后端与 MySQL。
- 按业务逐步发展为模块化单体，逐步建立模块接口、数据归属与依赖检查。
- 云端目标为 ECS 上的 Nginx 与 Java，独立 RDS MySQL 通过内网连接；配置模板见 `deploy/aliyun/`。
- 使用 AI 辅助资料检索和软件开发，首版暂缓面向用户的 AI 功能。
- 共同实现：AI 解释并提供小块示例，用户参与实现、修改、解释和验证。
- 以里程碑推进，固定交付日期、云资源规格与采购费用在实际实施前确定。

## 资料规则

AI 检索公开资料并整理草稿，保存原始来源；负责人对照出处核对后决定发布。暂时缺少可信出处或来源相互矛盾的内容留待核实。

语言音频优先寻找可靠原始资料；不足时可联系母语者补充或核对。文化文字、歌曲背景与可直接用作语言教材的素材分别核实。

用户投稿必须经过核对后才能公开。首版无论坛、自由公开发帖与评论功能；涉及特殊内容的实际服务范围和上线要求在发布前另行核实。

## 开发顺序

1. 文化文章从数据库，经 Java 接口，显示到手机页面。
2. 称呼、问候和家庭短句，以及经过核实的音频。
3. 歌曲介绍和原始收听入口。

每一块经历理解需求、实现、用户亲手修改和验证。第一批内容可用后，负责人邀请 3–5 位朋友或家人试用，观察他们读了什么、哪里有困难，以及是否用上一句学到的表达。

## 仍待对应阶段细化
