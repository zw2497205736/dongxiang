# 0001：采用 ECS、Nginx、模块化单体与独立 RDS

状态：架构方向已确认；云资源采购与部署待完成。

确认日期：2026-11-09。

## 决定

- 用户通过微信或手机浏览器访问网站，React 前端与 Java 后端通过 HTTP / JSON 通信。
- ECS 运行 Nginx 和 Spring Boot。Nginx 提供前端静态文件、处理 HTTPS、转发 `/api`。
- Java 按业务逐步形成模块化单体，模块内部按职责组织，模块之间逐步建立明确接口和依赖检查。
- 采用独立 RDS MySQL，ECS 经同地域、同 VPC 内网连接数据库。
- 数据库凭据只提供给后端，云端建表与内容导入显式执行。
- OSS、Redis、向量检索、队列和独立 Worker 根据真实需求增加。

## 原因与扩展方式

当前为个人开发，重点是内容、语言学习与完整工程能力。一个应用能控制部署复杂度；业务模块与数据归属为功能扩展提供位置。

访问增长后可以按实际瓶颈调整资源与增加应用实例。媒体文件、长任务、共享状态与任务幂等需要在相应功能落地时设计。出现明确的独立部署需求时，再拆出对应进程或服务。
